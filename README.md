# Fisheye StitchR

A free Mac app that joins two back-to-back circular fisheye pictures (for example two 220 degree star-trail
stacks, or one Insta360 X4 photo that holds both lenses) into one 360-style panorama.

Run it from source with `./run.sh`. Run the tests with `.venv/bin/python -m pytest`.

Not signed or notarized, the same as Star Trail CleanR.
